Self-hosted font subsets used by the Nefertiti public site.

- Playfair Display, by Claus Eggers Sørensen (SIL Open Font License 1.1)
- Source Sans 3, by Adobe (SIL Open Font License 1.1)
- Amiri, by Dr. Khaled Hosny and Sebastian Kosch (SIL Open Font License 1.1)
- IBM Plex Sans Arabic, by Bold Monday and IBM (SIL Open Font License 1.1)

These are official Google Fonts woff2 subsets (latin, latin-ext and Arabic)
for the weights used on the site. The complete licence text of the SIL OFL
is at https://scripts.sil.org/OFL.
